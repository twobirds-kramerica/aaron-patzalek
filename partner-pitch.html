The Model

A software studio that runs itself overnight

Most people using AI are using it like an assistant. I'm using it as the engineer. I spent six months building the infrastructure — the shop floor — before worrying about the products that sit on top of it.

The result: an idea can land in a backlog at midnight and have committed code, passing smoke tests, and a health report waiting for me by morning. One person running a studio that ships like a five-person team.

The tech stack is deliberately sovereign — I own it. GitHub Pages instead of Vercel, Python stdlib instead of npm packages, Windows Task Scheduler instead of a cloud cron service. Same instinct as running Nagios on-prem instead of paying for a monitoring SaaS. You build it once, you own it, it doesn't fail when a pricing tier changes.

Governance

The hard rules — enforced on every sprint

These aren't preferences. They're gates. If a rule fires, the sprint stops until it's cleared.

🔒
Design Gate
Fires before any UI sprint starts
Four conditions must be true before a UI sprint locks: PRODUCT.md exists for the product, /impeccable audit has run this quarter with findings documented, Aaron has approved the shape brief for structural changes, and dark mode tested on Android Chrome. Any one missing — sprint doesn't start.
🧑‍🤝‍🧑
Persona Panel Review
Fires at every Stage 3+ sprint completion
Before results are committed, the sprint is reviewed by a panel of 51 AI personas: the Scrappy Pack (The Researcher, Why Not, The Fifth Why, The Ripper, The Sovereignty Check), the Founding Board (22 personas across six departments), and the Inner Circle. A REWORK verdict blocks the commit. The panel exists to catch what a solo operator misses when heads-down in the work.
🎙️
Voice Check
Fires before any content leaves the system
Every email, landing page, outreach draft, or grant submission is scanned against a banned word list — hedging language, filler phrases, over-promising claims. A compliance tag is appended proving the scan ran. Nothing goes out unscanned.
🛡️
Sovereignty Check
Fires before any tool is added to the stack
Before any SaaS, API, or third-party dependency is recommended, a decapitation checklist is consulted. The question: if this service disappears tomorrow, what breaks? Self-hosted or open-source equivalent required first. No paid service without proof no sovereign alternative exists. Same instinct as running Nagios on-prem.
⚡
Autonomy Gate (AWR)
Fires before any task is filed to Aaron's queue
A 3-point check before any task reaches Aaron: (1) Can PowerShell or Python execute this? (2) Can an MCP tool handle it? (3) Does it only need files and scripts? If any answer is yes — the agent does it, no human involved. Only genuinely human tasks (physical action, legal signing, strategic judgment) ever reach the queue.
🔢
Token Guard
Always on — limits every AI session
Hard limit of 50 tool calls per AI turn. Prevents runaway sessions where the AI loops without making progress, burning compute and context window. Resets on each new message. The guard fired three times while building this system — it paid for itself on day one.
