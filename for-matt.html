The Model

A software studio that runs itself overnight

Most people using AI are using it like an assistant. I'm using it as the engineer. I spent six months building the infrastructure — the shop floor — before worrying about the products that sit on top of it.

The result: an idea can land in a backlog at midnight and have committed code, passing smoke tests, and a health report waiting for me by morning. One person running a studio that ships like a five-person team.

The tech stack is deliberately sovereign — I own it. GitHub Pages instead of Vercel, Python stdlib instead of npm packages, Windows Task Scheduler instead of a cloud cron service. Same instinct as running Nagios on-prem instead of paying for a monitoring SaaS. You build it once, you own it, it doesn't fail when a pricing tier changes.
The Workflow

From idea to live — one sprint

1
Idea → Notion backlog
Sprints are filed with priority, effort/return rating, and owner. A Python vetting script blocks any task the agent should just handle autonomously — nothing hits the human queue that doesn't need a human.
Python + Notion API
2
next-sprint.py locks the sprint
A script pulls the top Ready item, marks it In Progress in Notion, prints the brief to the terminal. No manual copy-paste. Design-gated UI sprints are automatically skipped until the gate is cleared.
Notion sync · auto-lock
3
Claude Code CLI executes
The AI agent reads the codebase, writes and edits files, runs PowerShell and Python, commits to Git — all in the terminal. I can walk away. A token guard limits runaway sessions to 50 tool calls per turn.
Autonomous · monitored
4
Static HTML pushed to GitHub Pages
No build step, no Node.js, no npm in the product repos. Git push → GitHub deploys in seconds. Zero hosting bill. WCAG accessibility checks run automatically via GitHub Actions on every push.
Git · GitHub Pages · axe-core CI
5
Overnight build at 2am
Playwright smoke tests, Lighthouse audits, backlog health, live data refresh, 10-repo sync, uptime monitor. Windows Task Scheduler — no external cron service.
Playwright · Python · Task Scheduler
6
Session-start health check
Six checks fire when I open the terminal: smoke test status, overnight build age, autonomy audit (agent-doable items cleared before I see anything), monitoring summary. Aaron sees only what genuinely needs a human.
AWR enforcement loop

Architecture Principle

Sovereign by design — every tool gets audited

Before any tool lands in the stack, it passes a sovereignty check. The question: if this service disappears tomorrow, what breaks? Same logic as self-hosted vs. cloud in traditional IT.
